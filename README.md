## Environment Variables

Set the following variables before running the application:

- `DB_SERVERNAME` – database server host (e.g., `localhost`)
- `DB_USERNAME` – username for the database
- `DB_PASSWORD` – password for the database user
- `DB_DATABASE` – name of the database

## Usage

Open `index.html` in a browser. The form submits to `index.php`, which inserts
the data into the `comment` table using the above environment variables for the
connection.
